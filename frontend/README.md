# ChartCraft - Statistical Analysis Made Simple

ChartCraft is a powerful web-based statistical analysis tool built with Next.js that enables users to perform comprehensive data analysis without requiring any backend infrastructure. It provides an intuitive interface for data upload, cleaning, and visualization.

## Features

### Data Management
- **CSV Upload**: Drag-and-drop or select CSV files for analysis
- **Column Selection**: Choose specific columns relevant to your analysis
- **Data Cleaning**: 
  - Support for various numerical formats:
    - Basic numbers
    - Currency ($)
    - Percentages (%)
    - Comma-separated numbers
    - Denominations (B, M, K)
  - Automatic data normalization
  - Custom data type mapping

### Statistical Analysis

#### Univariate Analysis
- **Descriptive Statistics**
  - Mean
  - Median
  - Mode
  - Variance
  - Standard Deviation
- **Distribution Analysis**
  - Skewness
  - Kurtosis
- **Visualizations**
  - Histograms
  - Box Plots

#### Bivariate Analysis
- **Correlation Analysis**
  - Pearson Correlation
  - Spearman Correlation
- **Regression Analysis**
  - Simple Linear Regression
- **Group Comparison**
  - T-Test

### Visualization
- Interactive charts using Recharts and Plotly.js
- Multiple chart types:
  - Bar Charts
  - Line Charts
  - Scatter Plots
  - Box Plots
  - Regression Plots
- Download charts as PNG
